# Shortcut icon

`rem-downloader.png` is the transparent source image; `rem-downloader.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel variants. Generated image metadata was removed when exporting the project assets.

Created with the built-in image generation tool using this prompt:

> Create one polished Windows desktop app icon for Rem Downloader, a Rem/Re:Zero themed terminal video downloader. Square 1024x1024 composition. Large recognizable adorable chibi Rem face, blue bob haircut covering one eye, one bright blue eye, white maid headband and small pink hair ribbon. Crisp simplified anime vector-like illustration with bold clean edges, restrained details readable at 32 pixels. Dark near-black navy rounded-square tile behind the portrait, thin subtle cyan edge. A small bold cyan downward download arrow in the bottom-right, integrated naturally. Face fills 75% of icon. No text, no lettering, no watermark, no desktop screenshot or mockup, no extra objects. Transparent pixels outside the rounded-square tile. Professional high-contrast blue/cyan/pink palette matching a dark terminal UI.
